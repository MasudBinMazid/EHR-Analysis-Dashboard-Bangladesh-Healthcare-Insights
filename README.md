# 📊 EHR Analysis Dashboard – Bangladesh Healthcare Insights

This project presents a complete **Power BI dashboard** built using a synthetic **EHR relational dataset** designed for the Bangladesh healthcare context.  
The dashboard uncovers meaningful insights across patient encounters, diagnoses, medicines, vitals, and geographic distribution of care.

---

## 🚀 Project Overview
The goal of this project is to:

- Analyze electronic health records (EHR) at scale  
- Identify trends in diagnoses, encounters, medication usage, and demographics  
- Visualize nationwide health activity using map-based insights  
- Build a clean, interactive one-page Power BI dashboard with slicers and KPI summaries  
- Provide a foundation for healthcare analytics in Bangladesh

---

## 📁 Data Model
A fully relational dataset was generated with tables:

- **Patients**
- **Encounters**
- **Facilities**
- **Providers**
- **Diagnoses**
- **Vitals**
- **Labs**
- **Medications**

A dedicated **Date Table** was used to enable time-intelligence (MoM, YTD, trends).

---

## 📌 Key KPIs
The dashboard highlights:

- **Total Patients**
- **Total Encounters**
- **Average Visits per Patient**
- **Encounter Trends (Monthly)**
- **Top Diagnoses**
- **Encounters by Gender**
- **Encounters by Medicine**
- **Facility-wise Encounters (Map Visualization)**

---

## 🗺️ Major Visuals
- **Disease frequency bar chart**
- **Encounter trend line chart**
- **Gender distribution donut**
- **District-level encounter map**
- **Medicine encounter bar chart**
- **Year & month slicers for flexible filtering**

---

## 📈 Insights from the Analysis
- COVID-19, Asthma, and Diabetes dominate the diagnosis distribution.  
- Encounter counts show subtle seasonal variations across months.  
- Gender distribution is nearly balanced across the dataset.  
- District-level analysis identifies Dhaka, Chattogram, and Rajshahi as high-encounter hubs.  
- Medicine encounters highlight Metformin, Salbutamol, and Azithromycin as top prescribed drugs.
